# Словари интерфейса (FR-8.1)

`ru.json` — образец со всеми ключами: русский текст уже встроен в код, файл нужен как шаблон.

Чтобы добавить язык (без изменения кода):
1. Скопируйте `ru.json` в `ky.json` (или `en.json`) и переведите значения, ключи не меняйте.
2. Переведите материалы: «Редактор → Переводы».
3. Включите язык: «Пользователи → Языки». На сайте появится переключатель.

Ключа нет в словаре — показывается русский текст.

Сейчас есть `ky.json` (кыргызский) и `en.json` (английский) — переводы стоит проверить носителю языка.

## Что переводится (FR-8.2)

Весь интерфейс на всех страницах: меню, главная, юрта (включая тексты всех 15 элементов — ключи `yurt.<элемент>.<поле>`),
традиции, фольклор, викторины и результаты, рейтинг, кабинет, вход и регистрация, редактор, администрирование.
Даты выводятся в формате выбранного языка.

Помощники из `src/i18n.ts`:
- `t('ключ', 'Текст')` — обычная надпись;
- `tf('ключ', 'Набрано {0} из {1}', a, b)` — надпись с подстановкой;
- `tp('plural.points', n, 'очко', 'очка', 'очков')` — слово после числа; в словарях ky/en ключи `.one` и `.other`;
- `lrec('префикс', { ... })` — справочник подписей на уровне модуля (переводится при каждом обращении);
- `ts(текст)` — системные тексты сервера (уровни, значки, строки начисления очков, описания ролей):
  ключ в словаре — `srv:` + русский текст.

Редакционный контент (обряды, категории, герои, произведения) переводится в «Редактор → Переводы».

Как перевести новую надпись в коде: вместо `"Текст"` написать `t('раздел.ключ', 'Текст')`
(компонент перерисовывается при смене языка, потому что `App` подписан через `useI18n()`), затем добавить
этот ключ во все файлы словарей.
