# Muras Interactive — архитектура этапа 1 (20%)

Учебная информационная система изучения культуры Кыргызстана.

## Задачи до 30.10.2026
- Эркайым: FR-1.1 схема юрты; FR-1.2 карточка элемента.
- Адинай: FR-6.1 регистрация/вход/выход/восстановление пароля; FR-2.1 категории обрядов; FR-2.2 карточка обряда.

Это **каркас папок**, а не готовое приложение. Чтобы запустить сайт, далее нужно создать Spring Boot Maven-проект (Java 17+, Spring Web, Thymeleaf, Spring Data JPA, PostgreSQL Driver, Spring Security) и реализовать классы.

## Структура
- `src/main/java/kg/murasinteractive/yurt/` — код юрты (Эркайым)
- `src/main/java/kg/murasinteractive/rite/` — код обрядов (Адинай)
- `src/main/java/kg/murasinteractive/auth/` — код авторизации (Адинай)
- `src/main/java/kg/murasinteractive/common/` — общие компоненты, изменения согласовывать
- `src/main/resources/templates/` — страницы Thymeleaf
- `src/main/resources/static/` — CSS, JS, изображения
- `database/` — SQL и схема данных
- `docs/` — документация и распределение задач

## Правила совместной работы
1. Одна репозитория, две отдельные ветки: `feature/yurt` и `feature/auth-rites`.
2. Каждая работает в своей ветке и папках. Общие файлы меняем после согласования.
3. Пушим изменения в свою ветку, затем создаём Pull Request в `main`.
4. Перед началом работы обновляем `main` через `git pull origin main`.
5. Не загружаем пароли, `.env`, `target/`, файлы IDE и личные настройки.

## Следующий шаг
Создать настоящий Spring Boot Maven-проект в корне репозитория, затем перенести/сохранить эту структуру. Каркас намеренно не содержит `pom.xml` и исполняемых Java-классов, чтобы не создавать впечатление, что функции уже реализованы.
